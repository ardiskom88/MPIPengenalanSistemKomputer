Perangkat Keras (Hardware)

Komponen fisik komputer yang mengolah data berdasarkan siklus IPO (Input - Process - Output).


1. Input Device (Masukan)

Perangkat untuk memasukkan data/perintah (Contoh: Keyboard, Mouse, Scanner, Mikrofon).

2. Process Device (Pemrosesan)

Otak komputer yang mengolah data: CPU (terdiri atas ALU, CU, dan Register) & GPU.

3. Storage Device (Penyimpanan)

Primary: RAM (Volatile), ROM (Non-volatile).
Secondary: SSD, HDD, Flashdisk.

4. Output Device (Keluaran)

Menampilkan hasil olahan data (Contoh: Monitor, Printer, Speaker).

Perangkat Lunak (Software)

Sekumpulan instruksi/program elektronik yang mengontrol hardware.


  • Sistem Operasi (OS): Pengelola utama sumber daya komputer (Contoh: Windows, Linux, macOS, Android).
  • Program Aplikasi: Software khusus untuk membantu pekerjaan (Contoh: Ms. Word, Chrome, Photoshop).
  • Bahasa Pemrograman: Alat untuk membuat software (Contoh: Python, C++, JavaScript).
  • Program Utility: Software penunjang perawatan sistem (Contoh: Antivirus, WinRAR).

Pengguna Komputer (Brainware)

Manusia yang mengoperasikan dan merancang sistem komputer.


  • System Analyst: Merancang arsitektur sistem.
  • Programmer: Menulis kode/membuat aplikasi.
  • Administrator: Mengelola jaringan & database.
  • Operator / End-User: Pengguna akhir aplikasi sehari-hari.
